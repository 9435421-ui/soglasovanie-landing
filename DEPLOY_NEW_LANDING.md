# Инструкция по размещению нового лендинга ТЕРИОН

Чтобы новый лендинг появился на сайте **http://ternion.ru/**, выполните следующие шаги:

### Шаг 1: Примите изменения на GitHub
1. Зайдите в ваш репозиторий на GitHub.
2. Перейдите во вкладку **Pull Requests**.
3. Найдите последний запрос от меня (Jules).
4. Нажмите кнопку **Merge pull request** и затем **Confirm merge**.

### Шаг 2: Обновите файлы на сервере (Деплой)
После того как вы объединили ветки на GitHub, выберите один из способов:

#### Способ А: Через терминал (если есть доступ к серверу 176.124.219.183)
Выполните эти команды:
1. Перейдите в папку бота: `cd /root/PARKHOMENKO_BOT`
2. Обновите код из GitHub: `git` + `pull` (команда загрузки)
3. Перезапустите бота: `pm2 restart terion-bot`

#### Способ Б: Вручную через FTP/SFTP
1. Скачайте файл `index.html` из вашего репозитория GitHub.
2. Загрузите его на ваш хостинг, заменив старый файл в корневой директории сайта.
