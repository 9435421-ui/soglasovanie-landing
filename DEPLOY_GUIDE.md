# 🚀 Инструкция по запуску ТЕРИОН v2.0

Этот проект полностью готов к работе. Чтобы запустить его на вашем сервере, выполните следующие шаги:

## 1. Подготовка окружения
Убедитесь, что у вас установлен Python 3.10 или выше.

```bash
# Установка зависимостей
pip install -r requirements.txt
```

## 2. Настройка ключей (.env)
Создайте файл `.env` в корневой папке проекта на основе примера:
```bash
cp .env.example .env
```
Откройте его и вставьте ваши реальные токены:
*   `BOT_TOKEN`: получите у @BotFather.
*   `OPENROUTER_API_KEY`: для работы ИИ (Антона).
*   `ADMIN_ID`: ваш числовой ID в Telegram (можно узнать у @userinfobot).

## 3. Запуск бота
Для первого запуска и проверки:
```bash
python3 bot_unified.py
```

Для постоянной работы (рекомендуется использовать **PM2**):
```bash
pm2 start bot_unified.py --name terion-bot --interpreter python3
```

## 4. Как протестировать
1.  **Квиз**: Напишите боту `/start` и нажмите «Начать расчет». Пройдите все шаги.
2.  **ИИ-консультант**: Нажмите «Консультация Антона» и задайте вопрос по перепланировке.
3.  **Админка**: Напишите `/admin`. У вас должна появиться кнопка управления контентом и очистки сервера.
4.  **Лендинг**: Если бот запущен, новости на сайте `index.html` начнут подтягиваться автоматически через API.
